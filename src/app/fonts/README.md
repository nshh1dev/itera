# Source Sans 3

Fuente variable original de Adobe, distribuida bajo SIL Open Font License 1.1 (`OFL.txt`).

Origen: https://github.com/google/fonts/tree/main/ofl/sourcesans3

Se incluyen los archivos originales normal e italic, con pesos 200–900, sin modificaciones. Next.js los sirve localmente mediante `next/font/local`; ni el arranque ni el build necesitan descargar fuentes.
